Build a to-do list that saves with AI

Add tasks, tick them off, delete them, clear finished ones. Your list is still there when you reload, because it saves in your browser.

Step 1 · Add

Add tasks to a list

Create a single-file to-do app: one index.html with CSS and JavaScript inside, no libraries. Keep tasks in an array called tasks where each item is { text: "...", done: false }. A form with a text box and an Add button adds a task (pressing Enter should also work). Ignore empty or spaces-only input. Write one render() function that rebuilds the list from the array. Set task text with textContent, not innerHTML.

Checkpoint: Add three tasks. Try adding an empty one: nothing should happen.

If it breaks: "Pressing Enter reloads the page. Explain preventDefault and fix it."

Give each task a checkbox and a Delete button. Ticking the checkbox sets done to true and shows the text crossed out. Delete removes that task from the array. After every change, call render().

Remember tasks after reload

Save the tasks array to localStorage under the key "tasks" every time it changes, using JSON.stringify. When the page loads, read it back with JSON.parse, or start with an empty array if nothing is saved.

Finished code · tested

The complete file

Copy this into index.html and open it in your browser. This is the same file as the demo.

<!doctype html>
<html lang="en">
<head>
<meta charset="utf-8">
<meta name="viewport" content="width=device-width,initial-scale=1">
<title>To-do list</title>
<style>
  body { margin: 0; font-family: system-ui, sans-serif; background: #f9fafb; color: #111827; }
  main { max-width: 520px; margin: 40px auto; padding: 0 16px; }
  form { display: flex; gap: 8px; }
  input[type=text] { flex: 1; min-width: 0; padding: 12px; font: inherit; border: 1px solid #e5e7eb; border-radius: 8px; }
  button { font: inherit; padding: 10px 14px; border-radius: 8px; border: 0; background: #4f46e5; color: #fff; cursor: pointer; }
  ul { list-style: none; padding: 0; }
  li { display: flex; align-items: center; gap: 10px; background: #fff; border: 1px solid #e5e7eb;
       border-radius: 8px; padding: 10px 12px; margin: 8px 0; }
  li span { flex: 1; overflow-wrap: anywhere; }
  li.done span { text-decoration: line-through; color: #9ca3af; }
  li button { background: none; color: #dc2626; padding: 4px 8px; }
  #footer { display: flex; justify-content: space-between; align-items: center; color: #6b7280; }
  #clear { background: none; color: #4f46e5; padding: 4px 0; }
</style>
</head>
<body>
<main>
  <h1>My to-do list</h1>
  <form id="add-form">
    <input id="new-task" type="text" placeholder="What do you need to do?" aria-label="New task" maxlength="200">
    <button type="submit">Add</button>
  </form>
  <ul id="list"></ul>
  <div id="footer"><span id="count"></span><button id="clear" type="button">Clear done</button></div>
</main>
<script>
// --- Load saved tasks (or start with an empty list) ---
// Each task looks like: { text: "Feed the cat", done: false }
let tasks = JSON.parse(localStorage.getItem("tasks") || "[]");

const form = document.getElementById("add-form");
const input = document.getElementById("new-task");
const list = document.getElementById("list");
const count = document.getElementById("count");

// --- Save tasks so they survive a page reload ---
function save() {
  localStorage.setItem("tasks", JSON.stringify(tasks));
}

// --- Rebuild the list on the page from the tasks array ---
function render() {
  list.innerHTML = "";
  tasks.forEach((task, i) => {
    const li = document.createElement("li");
    if (task.done) li.className = "done";

    const box = document.createElement("input");
    box.type = "checkbox";
    box.checked = task.done;
    box.setAttribute("aria-label", "Done");
    box.addEventListener("change", () => { task.done = box.checked; save(); render(); });

    const label = document.createElement("span");
    label.textContent = task.text; // textContent is safe: it never runs HTML

    const del = document.createElement("button");
    del.textContent = "Delete";
    del.addEventListener("click", () => { tasks.splice(i, 1); save(); render(); });

    li.append(box, label, del);
    list.appendChild(li);
  });
  const left = tasks.filter(t => !t.done).length;
  count.textContent = left + (left === 1 ? " task left" : " tasks left");
}

// --- Add a new task when the form is submitted ---
form.addEventListener("submit", e => {
  e.preventDefault();
  const text = input.value.trim();
  if (!text) return;
  tasks.push({ text: text, done: false });
  input.value = "";
  save();
  render();
});

// --- Remove every finished task ---
document.getElementById("clear").addEventListener("click", () => {
  tasks = tasks.filter(t => !t.done);
  save();
  render();
});

render();
</script>
</body>
</html>

Common problems

Tasks vanish on reload
You save but never load, or load before saving. Read localStorage once at the start, and save after every change.
[object Object] in storage
Use JSON.stringify to save and JSON.parse to load.
Typed HTML shows up formatted
Use textContent for user text. innerHTML runs it as HTML.
