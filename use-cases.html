Agent use cases

Which AI tools fit which job. Draft, editorial opinion

Rankings are subjective starting points, not benchmarks. Features change often; check each tool yourself.

Use case 1

Coding

Agents and assistants that help write, edit and debug software.

  1. CursorAI-first editor with agent mode working across a whole project.
  2. Claude CodeTerminal-based coding agent suited to multi-file tasks.
  3. GitHub CopilotWidely integrated in existing editors and workflows.
  4. ReplitBrowser-based, so beginners can build and run without setup.

Draft, editorial opinion.

Use case 2

Research

Tools that find, read and summarize sources.

  1. PerplexityAnswers with cited sources, handy for quick lookups.
  2. NotebookLMWorks over documents you upload, good for study and summaries.
  3. ChatGPTGeneral-purpose with web and file analysis features.
  4. GeminiHandles long documents and integrates with Google apps.

Draft, editorial opinion.

Use case 3

Game dev

Helpers for code, art, audio and design ideas.

  1. CursorHelps script gameplay in engines and web game frameworks.
  2. ClaudeGood for design docs, level ideas and explaining code.
  3. MidjourneyConcept art and visual style exploration.
  4. SunoQuick draft music and soundtrack ideas.

Draft, editorial opinion.

Use case 4

Automation

Connect apps and let routine tasks run without you.

  1. ZapierLarge app catalog and a gentle learning curve for first automations.
  2. n8nVisual workflows with more control, and a self-hosting option.
  3. MakeVisual scenario builder suited to multi-step flows.
  4. ChatGPTUseful for designing and troubleshooting the logic of a workflow.

Draft, editorial opinion.

Use case 5

Content creation

Making posts, images, video and audio for an audience.

  1. ChatGPTFlexible for outlines, drafts and repurposing one idea across formats.
  2. MidjourneyDistinctive images for thumbnails and covers.
  3. RunwayShort AI video clips and editing tools.
  4. ElevenLabsNatural-sounding voiceovers without a microphone.

Draft, editorial opinion.

Use case 6

Data analysis

Cleaning, exploring and explaining spreadsheets and datasets.

  1. ChatGPTCan analyze uploaded files and run code to chart results.
  2. ClaudeStrong at explaining findings in plain language.
  3. GeminiWorks well if your data already lives in Google Sheets or Drive.
  4. CursorHelps write and fix analysis scripts in Python or SQL.

Draft, editorial opinion.

Use case 7

Game testing

Finding bugs and balance problems before players do.

  1. Claude CodeCan write and run automated test scripts across a codebase.
  2. CursorHelps build debug tools and test scenes inside your project.
  3. GitHub CopilotSuggests unit tests as you write game logic.
  4. ChatGPTGood for brainstorming edge cases and playtest plans.

Draft, editorial opinion.

Use case 8

Learning

Understanding new topics and building skills faster.

  1. NotebookLMTurns your own notes and readings into summaries and Q&A.
  2. ChatGPTPatient tutor for explanations, quizzes and practice.
  3. ClaudeClear step-by-step explanations, handy for code concepts.
  4. PerplexityQuick answers with sources you can follow up on.

Draft, editorial opinion.
